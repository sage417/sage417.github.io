## 问题背景
当你有多地办公时，异地组网是多地计算机数据互通的必备功能，总不可能通过公网服务转发敏感数据，wireguard是一个轻量且加密的隧道工具，通过合理配置能够实现异地组网，移动设备远程接入

wireguard设计上属于对等节点，因此在配置上稍显复杂，这次的实战聚焦两地互通，多地互通可以以此作为参考配置

## 总体思路
在路由器中部署wireguard，让其子网下设备实现透明传输，在远程移动设备中部署wireguard客户端，需手动启动后接入，当然存在有以下限制条件： 1.多地路由子网不能重复 2.移动端wg接口地址不能自动分配，需要在对等节点上共同配置


## 网络架构

|设备 	| 子网 	| 网关 	| wg接口地址 	|  	|
|---	|---	|---	|---	|---	|
|Router1  	|192.168.35.0/24(vlan) 192.168.2.1/32(wan)  	|192.168.35.1/24  	|192.168.32.2/24  	|  	|
|Router2  	|192.168.31.0/24(vlan) 192.168.1.1/32(wan)  	|192.168.31.1/24  	|192.168.32.1/24  	|  	|
|移动设备  	| 无 	|无  	|192.168.32.100/32  	|  	|

公私钥配置不在重复，网络上教程一抓一大把，重点在于两个Router中AllowedIPs的配置，需要填写通过wg接口路由的地址，比如对于Router1而言，192.168.31.0/24, 192.168.1.1/32, 192.168.32.0/24这三类地址的数据包出口是wg接口才能正常通信

Router 1 cosplay 服务端 接受连接

```
[Interface]
ListenPort = 51820
PrivateKey = 

[Peer]
PublicKey = 
AllowedIPs = 192.168.31.0/24, 192.168.1.1/32, 192.168.32.0/24
Endpoint = xx:xx:xx:xx:12160

[Peer]
PublicKey = 
PresharedKey = 
AllowedIPs = 192.168.32.100/32
Endpoint = xx:xx:xx:xx:10189
```
Router 2 cosplay 客户端 发起连接

```
[Interface]
ListenPort = 51820
PrivateKey = 

[Peer]
PublicKey = 
PresharedKey = 
AllowedIPs = 192.168.32.100/32

[Peer]
PublicKey = 
AllowedIPs = 192.168.35.0/24, 192.168.2.1/32, 192.168.32.0/24
Endpoint = xx:xx:xx:xx:51820
PersistentKeepalive = 25
```
